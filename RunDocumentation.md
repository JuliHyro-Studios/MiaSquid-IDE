# Run Documentation

MiaSquid IDE provides two launchers:

- **`run.bat`**: Starts MiaSquid IDE on Windows using `npm run start`. Checks Node.js, npm, and `package.json` before launching.
- **`run.py`**: Starts MiaSquid IDE on Windows, Linux, and macOS. Checks Node.js, npm, and the `start` script before launching.

## Usage

- **Windows:** Run `run.bat`.
- **Linux / macOS:** Run `python3 run.py`.

**Requirements:** Node.js and npm must be installed.
